# Career Builder

A web application to help students make better academic plans by suggesting suitable branches and colleges.

---

## Overview

Career Builder is a tool designed for students facing the challenge of choosing the right branch or college. The decision can be overwhelming and requires a lot of research. This project aims to simplify that process by providing personalized suggestions based on a student's interests and academic strengths.

---

## How It Works

- **Input:** Students enter their interested subjects and their average marks in each subject.
- **Processing:** The app arranges subjects based on the student's performance.
- **Output:** The system suggests relevant courses and institutes that match the student's profile.
---

## Tools & Technologies

- **Frontend:** Bootstrap
- **Backend:** mySQL database, Apache Tomcat server
- **Development:** Eclipse IDE

---

## Database Schema

The application uses a structured database to store:
